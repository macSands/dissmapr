# Calculate Phi Coefficient

Phi coefficient for presence-absence; -1 to +1 pairwise, summary of
means/variances across combinations.

## Usage

``` r
phi_coef(vec_from, vec_to)
```

## Arguments

- vec_from:

  A binary presence-absence vector for the first site.

- vec_to:

  A binary presence-absence vector for the second site.

## Value

The Phi Coefficient value.
