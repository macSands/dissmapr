# Calculate Bray-Curtis Dissimilarity

Bray-Curtis dissimilarity on abundances; 0-1 for pairwise, averages or
totals for multi-site.

## Usage

``` r
diss_bcurt(vec_from, vec_to)
```

## Arguments

- vec_from:

  A numeric vector representing species abundances at the first site.

- vec_to:

  A numeric vector for species abundances at the second site.

## Value

The Bray-Curtis dissimilarity value.
