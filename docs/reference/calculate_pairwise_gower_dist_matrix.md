# Calculate Pairwise Gower Dissimilarity Matrix

Calculate Pairwise Gower Dissimilarity Matrix

## Usage

``` r
calculate_pairwise_gower_dist_matrix(df, sp_cols)
```

## Arguments

- df:

  A data frame containing site information.

- sp_cols:

  A vector of column names for species data.

## Value

A data frame containing pairwise Gower dissimilarities between sites.
