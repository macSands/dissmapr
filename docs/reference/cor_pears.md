# Calculate Pearson's Correlation

Pearson's correlation for linear abundance relationships; aggregated
across sites.

## Usage

``` r
cor_pears(vec_from, vec_to)
```

## Arguments

- vec_from:

  A numeric vector representing species abundances at the first site.

- vec_to:

  A numeric vector representing species abundances at the second site.

## Value

Pearson's correlation coefficient.
